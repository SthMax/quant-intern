# 个人信息保护合规审计管理办法

[官方原文及附件](https://www.cac.gov.cn/2025-02/14/c_1741233507681519.htm) · [原始HTML](../sources/REG-015/source.html) · [提取文本](../sources/REG-015/original.md) · [元数据](../sources/REG-015/metadata.json)

网信办令第18号，签发2025-02-12，官网公布2025-02-14，自2025-05-01施行。本轮未发现后续修订文本。

| 定位 | 核实的边界 | 应采取的项目动作 |
|---|---|---|
| 第3条；个保法第54条 | 个人信息处理者应定期开展审计，可内部开展或委托专业机构 | 把LLM个人信息处理纳入机构既有审计范围，不能说“未达千万可不审计” |
| 第4条 | **处理超过1000万人**个人信息的处理者，每两年至少一次 | 门槛是处理者规模，不是本PoC的样本行数；“超过”不能改为“达到” |
| 第5条 | 部门可在规定风险/事件下要求委托专业机构；有具体条件 | 不把外部专业审计写成每次LLM实验的法定先决条件 |
| 第6条及附件 | 开展审计应参照附录指引 | 可作为数据流、委托合同、自动化决策、影响评估和安全措施的检查目录 |
| 附件第六、九、二十三项 | 委托前评估与受托人监督；自动化决策检查；个人信息影响评估 | 区分事前影响评估、周期合规审计和技术模型评测，三者互不替代 |

尚未获得实习机构处理人数、现有审计周期或报告。本轮只是材料复核，没有执行机构级合规审计。具体检查见[复核结果](review-results-2026-09-09.md)。
