# 人工智能生成合成内容标识办法

[官方通知及全文](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm) · [原始HTML](../sources/REG-016/source.html) · [提取文本](../sources/REG-016/original.md) · [元数据](../sources/REG-016/metadata.json)

国信办通字〔2025〕2号，通知日期2025-03-07，官网公布2025-03-14，自2025-09-01施行。它是联合印发的规范性文件，不能仅因名称带“办法”就写成国务院行政法规。

| 定位 | 核实结论 | 本地研究LLM的边界 |
|---|---|---|
| 第2条 | 服务提供者范围衔接算法推荐、深度合成和生成式AI服务规定 | 先核实是否提供相应网络信息服务；纯内部用途不能直接套成所有平台义务 |
| 第4–5条 | 条件下的显式标识、文件元数据隐式标识；下载/复制/导出也有规定 | 面向客户或对外发布的产品，要把标识纳入导出链路 |
| 第6条 | 内容传播服务另有核验和提示职责 | 生成服务、传播平台、最终用户是不同角色 |
| 第9条 | 用户申请无显式标识内容存在协议和日志条件 | 不是随意移除标识的许可，且不等于豁免隐式标识 |
| 第10条 | 用户通过网络信息内容传播服务发布生成合成内容需声明并使用标识功能；禁止恶意破坏标识 | 内部生成后对外发布仍要重新判断，不能沿用内部使用结论 |
| 第11条 | 衔接强制性国家标准 | [GB 45438-2025官方平台](https://std.samr.gov.cn/gb/search/gbDetailed?id=301E0388CB75788DE06397BE0A0AE1B4)核实为强制性、现行，2025-09-01实施；本轮仅核状态，尚未完成全部文件格式技术符合性核验 |

标识、引用溯源和模型准确性各有用途，不能相互替代。本轮未判定实习机构的具体渠道或系统已满足标识要求。
