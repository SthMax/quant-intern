# 中华人民共和国数据安全法

[官方原文](https://www.cac.gov.cn/2021-06/11/c_1624994566919140.htm) · [原始HTML](../sources/REG-014/source.html) · [提取文本](../sources/REG-014/original.md) · [元数据](../sources/REG-014/metadata.json)

2021-06-10通过，2021-09-01施行。本轮重读有关条文并定向检索修订信息，未发现更新替代文本。

| 定位 | 复核结论 | 对本项目的含义 |
|---|---|---|
| 第2–3条 | 境内数据处理在范围内；数据不限于个人信息，处理包含收集、存储、加工、传输、提供、公开等 | 研报、模型输入、检索块、日志与输出需分别登记，不因无个人信息而无数据义务 |
| 第21条 | 分类分级保护及重要数据目录机制 | 区分“商业敏感”“个人敏感信息”“重要数据”，不要混用概念 |
| 第27条 | 全流程数据安全管理、教育培训和必要技术措施；重要数据有额外负责人要求 | 可把公开/合成数据用于原型，但生产数据接入需负责人分类与授权 |
| 第29–30条 | 风险监测、补救、事件报告；重要数据处理者定期评估并报送 | 不是所有研究数据都自动触发重要数据报送 |
| 第31条 | 重要数据出境按规定管理 | 结合REG-004、REG-006判断实际跨境活动 |
| 第32条 | 合法、正当收集数据 | 公开可访问不自动等于可无限制用于训练或再分发 |
| 第36条 | 外国司法/执法调取境内数据有专门限制 | 集团跨境支持与外国司法执法请求需区分，不能互相套用 |

本页不判定实习机构数据类别或某条出境路径已获许可。见[适用性与内部待确认表](review-results-2026-09-09.md)。
