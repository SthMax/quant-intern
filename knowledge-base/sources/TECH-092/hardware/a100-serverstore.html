  • Description
  • Product Features

The NVIDIA HGX 8x A100 80GB SXM4 NVLink GPU Server is a 4U, dual-processor server in a ZT Systems chassis with eight NVIDIA A100 GPUs.

It runs two AMD EPYC 7V12 processors with 64 cores each, for 128 cores total. It supports up to 2TB of DDR4 2933MHz memory across 32 slots.

The eight A100 80GB GPUs are connected with NVIDIA NVLink, which is faster than a standard PCIe connection. Networking is a 200Gb NVIDIA ConnectX-6 card, and power comes from six 3000W Titanium power supplies. This server works well for:

  • Training or fine-tuning large language models
  • AI and deep learning research
  • Computer vision and generative AI
  • Scientific computing and simulation
  • Running AI models for a large number of users

Quick Specs

  • GPUs: 8x NVIDIA A100 80GB SXM4 with NVLink
  • Processors: 2x AMD EPYC 7V12, 64 cores each (128 total)
  • Memory: Up to 2TB DDR4 2933MHz, 32 slots
  • Networking: Mellanox ConnectX-6 CX653105A VPI 1x200GbE/HDR QSFP56 PCIe Adapter
  • Power: 6x 3000W Titanium power supplies
  • Form Factor: 4U, ZT Systems chassis
