## 源文件与重新生成

- `src/revise-from-report.mjs`：导入旧PPT并按当前报告内容修改、扩展和重排页面。
- `src/slide-manifest.json`：各页标题、中文讲稿、来源及报告章节对应。
- `src/restore-chart-workbooks.py`：恢复导入导出过程中丢失的原始图表工作簿关联，保留原始工作簿字节与图表数据。
- `revise.sh`：调用Codex自带运行时生成新版本。

重新生成时指定新的文件名：

```bash
./revise.sh fund-llm-industry-next.pptx
```

脚本使用已归档资料和当前报告来源清单，不调用模型API或执行回测。构建与校验中间文件保存在忽略跟踪的目录。报告和知识库原件保持不变。

[旧版PPT](output/fund-llm-industry-2026-09-10-final.pptx)保留为本次导入源。`build.sh`与`src/build.mjs`属于旧版生成流程。
