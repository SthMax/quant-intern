你指出得对：我上一轮漏读了完整表格。清理后的网页文本省略了自定义表格，我没有继续核对原页的表头与模型行，就把它写成“缺少输出价格”，这是我的核验错误。

| 每百万tokens | 价格 |

| 普通未缓存输入 | ¥20 |
| 缓存读取 | ¥2 |

| 缓存写入，1小时 | ¥40 |
| **输出** | **¥100** |

本轮也核对了缓存说明：普通输入、写入和读取分别归类，计算时同一段输入只进入一个计费类别。基准使用1小时缓存，另算5分钟情景，输出包含在全部任务费用中。

在50人、每天5项、固定三年的基准情景里，Kimi输出费用单项为33万元；缓存写入与读取、输出合计246.84万元，再加43.5万元接入、技术运维与平台支持，三年预算为290.34万元。完整表格字段和计算记录已保存到配套数据文件。
