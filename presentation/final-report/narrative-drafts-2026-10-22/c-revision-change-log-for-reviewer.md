# C 修订版变更记录

供独立审稿逐项对照。依据 [新阅读体验反馈](c-reading-experience-feedback-for-user.md) 与 [initial draft](initial-draft.md)，输出 [修订正文](extended-draft-c-revised.md) 和 [修订证据](c-revised-evidence.md)。原 C 与原证据保留。

修订保留35页，讲述预算重新分配为40分钟。没有读取A/B全文或旧session，没有补入上一轮的全面候选内容，也没有扩大研究范围。

## 共性要求的处理

1. **句子用途**：逐页重写了回答假想误读的句子，删除“不能当作”“不等于”“不代表”“尚不能承诺”等解释。对标题、表头、图示标签、注释和末句同样处理。数字对象直接使用“外部测量”“全注意力KV载荷”“公开回放”“容量估算”“服务目标”“三年预算”等名称。
2. **段落组织**：开头用具体工作和机构案例建立认识，财报任务加入一个教学数字例，随后解释模型工作方式与窗口。选择理由改成连贯两段。推理过程、输入增长、八卡分组、性能增量分别采用对应的过程或组成表达。
3. **页面收尾**：删除多数泛化结论、重复主题和“仍需验证”式尾句。保留直接增加信息的收尾，如窗口保留的内容、扩容进入哪一年。最后一页统一收束研究与后续采用判断。
4. **事实条件**：研究对象、时间、设备、样本和计量单位尽量在数据之前或旁边交代。完整日志缺项、实现组合、软件SHA与详细适用边界集中到证据。更新措辞后再检查过强标题及缺失条件。
5. **时间**：按每页实际解释动作配置20–105秒，技术读图与多轮工作量留较多时间，开场、产品入口与结尾压缩。证据逐页说明讲述重点，合计2400秒。
